Zotero 与参考文献

由研究者选择官方来源并核实书目信息，使用 Zotero 和 Better BibTeX 管理论文中的参考文献。

更新于 2026-09-04
ZoteroBetter BibTeX
操作分工

AI 可以帮你找到候选文献、发现可疑字段。研究者从可核实的来源导入 Zotero，检查元数据后再统一导出。

Zotero 条目

导入后核对关键字段

待核实
作者与题名对照原文核实
年份与出处确认所引版本
DOI 或标识符检查是否指向同一工作
引用键确认稳定且没有冲突

准备工具

建议在 Mac 上准备 Zotero 桌面端、浏览器中的 Zotero Connector，以及 Zotero 的 Better BibTeX 插件。先完成这组工具的安装，再为当前研究建立一个 collection，集中整理准备阅读和引用的文献。

  • 从 Zotero 官网 安装桌面应用与浏览器 Connector。
  • 按 Better BibTeX 安装说明 安装插件。它安装在 Zotero 中。
  • 明确论文仓库中参考文献文件的位置，例如 paper/references.bib，并确认你正在使用 BibTeX 还是 biblatex。

导入文献

AI 或 Knows 给出一篇候选论文后，先打开 DOI 对应的页面、出版社页面或相应的官方记录，确认确实是你准备引用的那项工作。

有 DOI 等标识符时，可以在 Zotero 的“通过标识符添加条目”入口导入；浏览官方文章页面时，也可以使用 Connector 保存。导入后，先看条目有没有进入正确的 collection。

优先从文章页面获取记录，能够更清楚地确认出版信息与论文版本。如果手上只有 PDF，应检查它是否已经关联到完整的文献条目。Zotero 导入说明

这里所说的“人工导入”，是由研究者选择来源、发起导入并检查结果，无需逐字录入所有字段。

核实元数据

导入成功后，对照官方来源检查关键字段。尤其在预印本、会议版与期刊扩展版同时存在时，应明确正文引用的是哪一个版本。

检查项需要确认什么
作者与题名作者顺序、姓名拼写、题名是否对应原文
年份与出处出版年份、会议或期刊名称、所引版本
卷期与页码原始来源是否确实提供这些字段；文章编号是否被误作页码
DOI 或其他标识符能否定位到该条目，是否属于同一版本
条目类型期刊文章、会议论文、预印本或网页是否选择正确

这些检查也帮助你发现“正文讨论的是一个版本，参考文献列的是另一个版本”的问题。字段不存在时保留真实情况，不为补齐格式而填入猜测。

导出参考文献文件

核实好准备使用的条目后，将对应 collection 或选中的条目导出。对于使用 BibTeX 的论文模板，选择 Better BibTeX；若模板使用 biblatex，则选择对应的 Better BibLaTeX。文件格式要与论文工具链一致。导出说明

建议按下面的顺序处理：

  1. 确定需要导出的条目范围，减少无关文献混入。
  2. 检查引用键是否稳定、是否存在冲突。
  3. 导出到明确的文件位置，将其纳入论文的 Git 版本管理。
  4. 让正文使用已有引用键，编译后检查未定义引用与最终参考文献列表。

Better BibTeX 提供可定制、可固定的引用键，生成时会考虑库内已有键，有助于减少重名冲突。它并不替你保证作者、年份等元数据正确。合并不同人的导出文件时，也要重新检查重复条目和重复键。引用键说明

手动导出与自动覆盖

后续可能直接修正论文中的 .bib。手动导出便于先比较变化，再决定如何更新文件，避免自动导出覆盖已经核实的修正。

修正 .bib 中的错误

如果 AI 发现导出的条目有问题，可以提供当前值、建议值和官方依据。你核实并确认后，可以直接修改 .bib，无需回到 Zotero 重新导入。

例如，AI 指出年份与官方出版记录不符，应先检查是不是 online-first 年份、正式卷期年份或不同论文版本造成的差异。确认应该使用哪个记录后，再修改相应字段。

如果以后要重新导出同一文献库，先将新结果导出为另一份文件，例如 references.new.bib。通过差异比较保留已核实的修改，再更新论文使用的文件。

使用 Agent 检查引用

将已导出的书目文件和论文源文件交给 Agent，它可以帮你发现键是否缺失、同一键是否对应多条记录、字段是否可疑。建议让它把意见与来源一起列出来，便于你逐项核实。

Q&A

常见问题

4 个问题
Q01已经拿到一段 AI 生成的 BibTeX，可以直接使用吗？
A

建议先回到 DOI 或官方来源核实，并经 Zotero 导入和导出得到正式条目。AI 生成的字段可能有误，需要逐项核实。

Q02Better BibTeX 能保证完全没有引用冲突吗？
A

它能帮助管理引用键。合并多人文献库、手动改键或导入其他文件后，仍需要检查键与条目的对应关系。

Q03只修改 .bib，会不会让 Zotero 与论文文件不一致？
A

可能会。因此这套做法要求你在重新导出时比较差异、保留已核实修正。是否同时维护 Zotero 条目，可根据自己的工作习惯决定。

Q04没有 DOI 的文献怎么办？
A

使用适合该文献的官方记录或其他可信来源，如 arXiv 记录、机构发布页面或图书目录，并保留真实的版本与访问依据。
