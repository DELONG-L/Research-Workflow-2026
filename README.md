# How to Start Your Own Research in 2026

一本中文科研工作流手册，介绍从建立项目、检索文献、设计实验，到论文写作、协作与汇报的常用工具和操作方法。可以按章节阅读，也可以根据当前研究任务查阅。

**[在线阅读手册 →](https://delong-l.github.io/Research-Workflow-2026/)**

## 手册内容

全书共九章，按三个阶段组织：

| 阶段 | 章节 | 主要内容 |
| --- | --- | --- |
| 开始工作 | 01 ChatGPT 与 Skill<br>02 项目与上下文管理 | 选择工作模式，使用 Skill，建立统一项目目录并保存跨会话记录。 |
| 推进研究 | 03 文献与研究空白<br>04 Zotero 与参考文献<br>05 实验设计与记录<br>06 写作与图表 | 检索和比较文献，管理引用，记录实验方案与结果，依据研究材料撰写正文和制作图表。 |
| 协作与汇报 | 07 Git 与 Overleaf<br>08 审查、修回与汇报<br>09 调整工作流程 | 本地编译与同步论文，检查稿件，处理审稿意见，准备汇报并改进工作方式。 |

## 阅读时可以使用的功能

- **站内搜索**：按工具名称或关键词查找相关内容，直接进入对应章节或小节。
- **章节与页内目录**：切换章节、定位小节，并通过前后篇导航连续阅读。
- **可复制的 AI 操作指令**：展开完整指令，替换其中的占位信息后，用于自己的研究任务。
- **常见问题**：部分章节提供可展开的 Q&A，补充容易混淆的概念和操作细节。
- **配图与示例**：结合图片、对照表和记录示例理解目录组织、实验记录及论文协作方式。
- **工具与来源**：集中查看工具用途、官方说明和项目链接，便于继续查阅。

## 从哪里开始

第一次阅读，可以从[第一章：ChatGPT 与 Skill](https://delong-l.github.io/Research-Workflow-2026/guide/agents-skills/)开始。已有研究项目时，可以从[首页目录](https://delong-l.github.io/Research-Workflow-2026/#chapters)选择当前需要的章节，或使用[站内搜索](https://delong-l.github.io/Research-Workflow-2026/search/)查找具体问题。

手册中的工具和操作方式可以按项目需要选用，不必一次采用全部流程。查找工具的官方入口和相关项目，请查看[工具与来源](https://delong-l.github.io/Research-Workflow-2026/resources/)。
