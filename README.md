## 九章，一条研究路线

### 开始工作 · 01–02

- **[01 · ChatGPT 与 Skill][chapter-01]**<br>了解 Chat、Work 与 Codex 模式，区分本地和云端任务，选择、安装并检查 Skill、插件与工具连接。

- **[02 · 项目与上下文管理][chapter-02]**<br>确定项目目录，组织材料与论文仓库，保存跨会话记录，方便下次继续。

### 推进研究 · 03–06

- **[03 · 文献与研究空白][chapter-03]**<br>明确研究问题，检索并核对原文，比较最接近的已有工作，记录候选研究空白并安排初步验证。

- **[04 · Zotero 与参考文献][chapter-04]**<br>导入文献、核实元数据、管理引用键，导出 BibTeX 或 BibLaTeX，并检查正文引用。

- **[05 · 实验设计与记录][chapter-05]**<br>说明实验问题、比较条件与评价方法，记录方案和分析计划，保留每次运行与方案变化。

- **[06 · 写作与图表][chapter-06]**<br>从研究材料整理论文提纲，在明确范围内起草与修改，使用已核实的引用，从数据制作图表并检查排版。

### 协作与汇报 · 07–09

- **[07 · Git 与 Overleaf][chapter-07]**<br>建立论文仓库与本地 LaTeX 环境，读取远端变化、检查差异和编译结果，再同步文稿并处理冲突。

- **[08 · 审查、修回与汇报][chapter-08]**<br>找出稿件的主要问题，安排修改顺序，整理审稿意见与回复，用已有研究材料准备汇报。

- **[09 · 调整工作流程][chapter-09]**<br>检查重复操作和记录缺失，确定信息的维护位置，评估小范围调整，更新进展与交接记录。

## 边读边用

- **查得到，也接得上。** 全文搜索可按任务或工具定位内容；章节目录、页内目录和前后篇导航帮助连续阅读，小屏设备也可展开目录。

- **把指令带回自己的项目。** 29 条 AI 操作指令可以展开和复制，替换占位信息后使用。每条指令说明任务范围、所需材料与预期结果。

- **结合例子理解操作。** 16 个可展开的常见问题分布在五章中，配合场景插画、对照表、目录结构与记录示例，解释具体做法。
