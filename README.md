一本中文科研工作流参考手册，介绍从建立项目、检索文献、设计与记录实验，到论文写作、版本协作、修回与汇报的常用方法。全书共九章，按研究工作的三个阶段组织，既可以连续阅读，也可以根据当前任务查阅。

手册结合 ChatGPT、Skill、Zotero、Git、LaTeX 和 Overleaf 等工具，说明文件如何组织、工作状态如何保存，以及 AI 可以怎样协助具体任务。内容包括操作步骤、可复制指令、记录示例、对照表、配图和参考来源。工具与流程可以按项目需要选用，研究判断和材料核实仍需由读者完成。

**[在线阅读手册 →][handbook]** · [浏览全部章节][chapters] · [站内搜索][search] · [工具与来源][resources]

网站正文目前为中文；本仓库提供中文和英文两份 README。

## 怎样开始阅读

第一次阅读，可以先看[第 01 章：ChatGPT 与 Skill][chapter-01]，了解工作模式与工具连接，再看[第 02 章：项目与上下文管理][chapter-02]，为研究材料、代码和论文确定稳定的存放位置。

已有项目时，可以直接从当前需要处理的问题开始：

| 当前任务 | 建议查阅 |
| --- | --- |
| 创建研究项目，或继续上次的工作 | [项目目录与跨会话记录][chapter-02] |
| 寻找研究方向，整理文献与引用 | [文献与研究空白][chapter-03] · [Zotero 与参考文献][chapter-04] |
| 确定实验方案，检查运行记录与结果 | [实验设计与记录][chapter-05] |
| 起草论文，制作图表，编译并同步文稿 | [写作与图表][chapter-06] · [Git 与 Overleaf][chapter-07] |
| 处理审稿意见，准备汇报，调整工作方式 | [审查、修回与汇报][chapter-08] · [调整工作流程][chapter-09] |

## 九章内容

### 开始工作

| 章节 | 内容 |
| --- | --- |
| [01 · ChatGPT 与 Skill][chapter-01] | 介绍 Chat、Work 与 Codex 模式，本地与云端任务的区别，以及 Skill、插件和工具连接的用途；说明如何选择、安装和检查 Skill。 |
| [02 · 项目与上下文管理][chapter-02] | 先确定项目目录，再创建任务；组织研究材料与论文仓库，保存跨会话状态，向合作者共享进展。 |

### 推进研究

| 章节 | 内容 |
| --- | --- |
| [03 · 文献与研究空白][chapter-03] | 明确研究问题，检索并核对文献，比较最接近的已有工作，记录候选研究空白并安排初步验证。 |
| [04 · Zotero 与参考文献][chapter-04] | 导入文献、核实元数据、管理引用键，导出 BibTeX 或 BibLaTeX 文件，并检查正文引用与参考文献。 |
| [05 · 实验设计与记录][chapter-05] | 说明实验问题、比较条件和评价方法，记录方案与分析计划，进行小规模检查，保留每次运行及方案变化。 |
| [06 · 写作与图表][chapter-06] | 从研究材料整理论文提纲，按明确范围起草与修改，使用已核实的引用，从数据制作图表并检查实际排版。 |

### 协作与汇报

| 章节 | 内容 |
| --- | --- |
| [07 · Git 与 Overleaf][chapter-07] | 连接论文仓库，搭建本地 LaTeX 环境，读取远端变化，检查差异和编译结果，再同步到 Overleaf；处理冲突与误改。 |
| [08 · 审查、修回与汇报][chapter-08] | 检查稿件问题，安排修改顺序，整理审稿意见与回复，核查修订是否一致，并用已有研究材料准备汇报。 |
| [09 · 调整工作流程][chapter-09] | 检查重复操作与记录缺失，确定信息的维护位置，试用并评估工具或流程调整，更新进展与交接记录。 |

## 阅读功能

- **全文搜索**：按研究任务、工具名称或关键词查找内容，进入对应章节与小节。
- **章节与页内目录**：浏览九章内容、定位当前页面的小节，并通过前后篇导航连续阅读；小屏设备也可展开目录。
- **29 条可复制的 AI 操作指令**：展开指令、复制内容，替换占位信息后用于自己的项目。指令说明任务范围、需要检查的材料和预期结果。
- **16 个常见问题**：五个章节提供可展开的 Q&A，补充工作模式、项目组织、引用管理、实验与论文同步中的常见疑问。
- **配图、对照表与记录示例**：结合场景插画、工具图标、目录结构和记录样例理解具体操作。
- **工具与参考来源**：在[工具与来源][resources]页面集中查看工具和项目入口，也可从各章末尾继续查阅相关说明。

## 涉及的工具与工作方法

| 任务 | 手册介绍的工具或方法 |
| --- | --- |
| 与 AI 协作 | ChatGPT 的 Chat、Work 与 Codex 模式，Skill、插件和工具连接；也提供 Claude Code 相关项目入口。 |
| 整理项目与工作记录 | Research-Workflow-Skills、planning-with-files，以及项目目录和跨会话记录的组织方法。 |
| 检索、阅读与管理文献 | Knows、grilling、Zotero、Better BibTeX，以及原文核对和已有工作比较。 |
| 写作、图表与研究交流 | Academic-Paper-Skills、研究汇报与同行评审相关 Skill，以及稿件审查和修回记录。 |
| 版本管理与论文协作 | Git、GitHub、LaTeX、latexmk 与 Overleaf，包括本地编译、差异检查和远端同步。 |

可以先选择当前任务需要的工具，再根据使用情况调整。安装方式、可用功能和权限以工具官方说明及对应项目文档为准，相关入口汇总在[工具与来源][resources]。
