调整工作流程

检查重复操作与记录缺失，试用工具，并评估是否保留调整。

更新于 2026-09-24

其他位置保留摘要或可访问链接

检查重复操作与记录缺失

可以先回顾最近一段实际工作：哪些操作重复最多，哪里容易丢失信息，哪一步经常需要返工。选择其中一两个问题调整，比一次更换所有工具容易判断效果。

AI 操作指令

检查当前工作方式并提出小范围调整

查看完整指令
请根据【项目目录与近期工作记录】，检查我的科研工作方式。
先读取已有目录说明、计划和进展，不改变文件位置或安装工具。
找出有具体证据的重复操作、信息缺失或返工问题，说明它们出现在哪一步。
优先提出一到两项小范围调整，说明复用什么、增加什么，以及如何判断是否有帮助。
保留已经有效的做法；不要为了采用某个工具而重新组织整个项目。
输出一份简短建议，并列出需要我补充的信息。
将【占位信息】替换为实际内容后，再发送给 Agent。

确定信息的维护位置

同一项信息可以出现在多个地方，但建议确定主要维护位置。其他地方保存摘要或链接，避免在几份文件中反复更新相同内容。

信息或任务工具或保存位置
讨论、检索与材料处理ChatGPT；按任务选择模式与 Skill
代码、配置和版本项目目录与 Git
当前计划与执行细节项目已有记录，或 planning-with-files
文献条目与引用导出Zotero 与 Better BibTeX
实验方案和运行记录项目内的实验记录
远程计算HPC 项目目录与 Slurm 作业
论文源文件独立论文仓库与 Overleaf
协作进展与需要讨论的问题共享进展记录

例如，实验日志保存在项目里，共享进展只记录新结果及其位置。这样日志继续更新时，不需要把所有细节再复制一次。

HPC 项目目录与运行环境

远程计算继续使用本地项目的稳定名称：项目子目录尽量与本地目录同名。Conda 环境使用同一名称；uv 或 pip 使用项目独立 .venv，并由依赖文件重建环境。同步前确认代码、数据和结果各自的保存位置。

保存自己会反复使用的指令

可以从本手册复制指令，按自己的项目补充工作目录、材料位置、已有约定和期望输出。用过后再根据实际问题调整，不必把每次对话都写成很长的模板。

一条可复用指令通常需要说明四件事：这次要完成什么、依据哪些材料、可以处理哪些内容，以及完成后如何检查。涉及共享位置或外部操作时，再说明允许执行的范围。

长期适用的项目约定可以放在项目说明或 Agent 会读取的指引文件中；仅本次适用的要求放在任务里。个人账号、密钥和受限连接信息继续保存在相应的个人配置中。

试用工具或流程调整

选一个范围明确、结果容易检查的任务，例如整理一次组会进展、修改一个小节、复现已有脚本的输出。尽量一次只改变少量做法，这样可以知道变化是否有帮助。

试用后比较实际结果：需要补充多少次上下文，是否找得到产出和依据，是否减少了手工重复，以及是否引入额外维护工作。

评估使用效果

如果一个新工具只是多了一份待维护的记录，可以先减少记录字段、改成链接，或暂停使用。使用 Skill 时，写明任务范围与输出要求，并检查实际结果。

多个 Skill 都能处理同一任务时，先选择一个主要入口。安装更多工具之前，可以让 Agent 检查现有能力是否已能完成工作。安装与更新方法见 ChatGPT 与 Skill。

反复出现同一种错误时，把对应检查加进项目约定或常用指令。偶发问题可以先留在工作记录里，不必立即扩大整套流程。

按项目阶段组合步骤

各阶段可使用以下章节。实验结果可能需要补充文献比较，写作时也可能发现需要补充定义。

当前任务可以使用的章节相关记录
开始新项目ChatGPT 与 Skill、项目与上下文管理工作入口、材料位置与当前目标
判断候选方向文献与研究空白、Zotero 与参考文献已核实的文献、比较记录和待验证问题
执行研究实验设计与记录、计算资源方案版本、运行记录、结果与限制
整理论文写作与图表、Git 与 Overleaf与证据对应的稿件、图表及可恢复版本
讨论与交付共享进展记录、审查修回与汇报实际进展、交付材料和后续事项

文献检索、实验和写作可以交替进行。提前起草方法和实验计划，有助于发现研究设计中尚未明确的条件。

更新进展与交接记录

结束一段工作时，留下当前状态、材料位置、已经确认的判断、仍不确定的部分，以及一个具体的下一步。下次由自己、合作者或新的 Agent 接手时，都可以从这份记录继续。

交接信息尽量指向实际文件或版本。例如写明“检查哪次实验的哪份输出”，通常比“继续分析结果”更有帮助。项目中已有进度记录时直接更新，不必再创建新的交接文件。

更新进展与交接记录

查看完整指令
请根据本次会话和【项目目录】的实际变化，更新现有进展或交接记录。
写清当前目标、已完成事项、对应文件或版本、检查结果，以及尚未验证的判断。
记录仍在运行的任务编号和状态；不知道的状态明确标为待检查。
把下一步写成可以开始执行的具体任务，说明需要读取的材料和预期结果。
复用已有记录，不复制密钥、个人登录材料或私有连接参数。

如果这段进展需要共同讨论，可以整理一份较短的共享摘要。对外共享前确认链接可访问、材料适合共享，并区分已完成事项与未来计划。
