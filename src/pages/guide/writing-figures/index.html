写作与图表

论文提纲、正文修改、参考文献、数据绘图与稿件检查。

更新于 2026-09-24
Academic-Paper-SkillsOverleaf
图表检查

按论文实际尺寸查看

  • 字体、刻度和图例可读
  • 图注包含对象、单位与条件
  • 正文数字与图表一致
  • 保留数据、脚本和输出位置

准备写作材料与投稿要求

开始写一节内容前，先告诉 Agent 论文准备回答的问题、当前已有的证据、目标读者，以及这次要修改的范围。可以同时提供现有稿件、实验摘要、已核实的参考文献和相关图表。

已经确定投稿去向时，查看该会议或期刊当前的官方要求，包括模板、页数、匿名要求与补充材料安排。目标尚未确定时，可以先按研究内容组织文章，之后再调整格式。

我们主要使用 Academic-Paper-Skills。其中 paper-policy 处理适用规则，paper-writing 处理正文，paper-figures-tables 处理图表，paper-review 处理审查。安装和更新时保持四个 Skill 的版本一致。项目说明

以 Claude Code 为主要 Agent 时，可以参考 claude-scholar，按其实际提供的功能调整指令。

整理论文提纲

提纲可以写到段落要点的程度：这部分要说明什么、依据在哪里、读者还需要知道什么。不必先要求 AI 写满所有章节。

内容写作前可以准备的材料
问题与动机具体使用情境、已有方法的限制，以及相应文献
方法输入输出、关键步骤、设计理由与适用条件
实验实验方案、比较设置、结果表与分析记录
讨论与限制结果支持的解释、替代解释和未验证的范围

候选想法、正在运行的实验和已经取得的结果，应在材料中写明各自状态。尚未取得的证据可以留作待补充项，不让 Agent 用合理猜测写成已有发现。

AI 操作指令

依据现有材料整理论文提纲

查看完整指令
请使用 paper-writing，根据【论文目录】与【研究材料位置】整理提纲。
先读取现有稿件、实验摘要、图表和已核实的参考文献，说明当前可支持的主要主张。
按【目标读者或投稿去向】安排章节和段落要点，将每项主张对应到材料位置。
区分已有结果、探索性发现和待补充证据；不要补造数据、引文或实验状态。
如果已经指定投稿去向，先用 paper-policy 核对适用要求和来源日期。
本次只保存提纲及待补充材料清单，不直接重写整篇论文或同步到 Overleaf。
将【占位信息】替换为实际内容后，再发送给 Agent。

按具体范围起草与修改

一次可以先处理一个小节，说明希望解决的问题，例如定义不清、段落顺序不顺、主张超过实验范围，或句子太长。让 Agent 给出可以检查的修改，并说明哪些事实还需要补充。

改写时保留术语、符号、数据和限定条件的一致性。原文只在某个数据集或条件下观察到的现象，不应在润色后变成普遍结论。“提升了多少”也需要明确比较对象、指标与计算方式。

AI 操作指令

修改一节正文并保留证据范围

查看完整指令
请使用 paper-writing 修改【论文目录】中的【章节或文件范围】。
本次希望解决的问题是【表达、结构或论证问题】。先读取相关上下文和证据。
保留已核实的数字、术语、符号、引用键及限定条件；需要更正事实时单独指出依据。
缺少支持材料的表述列为待核实，不用合理猜测补全。
保存修改并给出主要差异及尚未解决的问题；条件允许时编译并检查相关页面。
保留其他人的修改，本次不向远端推送。
将【占位信息】替换为实际内容后，再发送给 Agent。

修改 LaTeX 时先查看差异，再编译检查。需要与 Overleaf 同步时，继续使用 Git 与 Overleaf 中的步骤。

使用已核实的参考文献

正文引用可以从已经人工核实的 .bib 和阅读笔记中选择。让 Agent 说明某篇文献支持哪一项表述，必要时回到原文核对，避免将摘要里的大致相关性写成直接证据。

缺少文献时，记录需要补充的主题或论据，再到 文献与研究空白 中检索。候选文献经过人工核实后导入 Zotero，由 Better BibTeX 导出；不让 AI 凭记忆生成正式参考文献。

AI 发现 .bib 元数据问题时，可以提出修改建议。人工核实后可直接修正文件，不必强制回到 Zotero；后续重新导出时保留已经核实的修正。具体方法见 Zotero 与参考文献。

从数据生成实验图表

先确定图表要帮助读者比较什么，再选择图形。比较方法性能、展示预算变化、检查分布或呈现失败案例，需要的形式可能不同。

数值图建议从 CSV、JSON 或实验日志生成，保留绘图脚本和对应的数据版本。坐标、误差线和数据点应由实际数据决定；需要修改数值时，先检查数据或计算过程，再重新导出图表。paper-figures-tables 可用于这种基于源数据的绘图工作。图表 Skill

AI 操作指令

从实验数据制作图或表

查看完整指令
请使用 paper-figures-tables，根据【数据文件及版本】制作【图或表的用途】。
先检查字段、单位、比较设置、缺失值和重复结构，说明适合呈现的内容。
所有数值由源数据计算；确认误差条或区间定义，不把缺失结果填成零。
保存处理与绘图脚本、数据来源记录、图注和可用于论文的导出文件。
按【目标栏宽或页宽】检查标签、图例、单位和数值一致性，并提供预览。
数据不足或分析定义不明确时先指出问题，不生成虚构结果，也不改动原始数据。
将【占位信息】替换为实际内容后，再发送给 Agent。

图注说明比较对象、单位、样本或重复次数，以及误差条代表什么。未运行、缺失、不适用和数值为零，建议使用不同表示；不能为了表格完整把缺失结果填成零。

安排方法示意图与对比表

方法图可以先写成一份说明：有哪些组成部分、输入输出是什么、箭头表示数据流还是执行顺序。确认关系后再绘制，减少来回调整。

工具选择取决于图的内容和后续修改方式。需要精确编辑的流程和结构图，可以使用可编辑的矢量工具；使用生成图像时，逐项核对文字、符号、连接和数量。示意图中的数值若只是举例，应当明确标注。

相关工作对比表中的每个判断也需要依据。没有核实的能力项先标记待确认，不因为论文没有提到某项功能，就直接认定它不支持。文献比较的方法见 比较最接近的已有工作。

在论文实际尺寸下检查

图表放入稿件后，再按实际栏宽或页宽查看。检查字体、刻度、图例、单位和注释是否可读，线条与箭头是否清楚，是否有裁切或被挤压的内容。适合矢量输出的图可以保存为 PDF 或 SVG，同时保留可编辑源文件。

检查正文、图注和表格是否使用同一批结果。重新分析数据后，如果只更新图片却没有更新正文数字，稿件仍会出现不一致。建议记录最终图表对应的数据、脚本和输出文件。

编译成功后还需要阅读实际 PDF，确认图表位置、交叉引用和参考文献。投稿前的整体检查见 审查、修回与汇报。
